# Contoso Sales Analytics – Requirements

## Project Overview

The goal of this project is to create a modern and interactive Power BI report using Contoso sales data.

The report should make it easy for users to understand sales performance, compare products and regions, and quickly identify important business trends.

## What the Report Should Help Answer

The report should help users understand:

* How are sales performing overall?
* Which products and categories are performing best?
* Which regions generate the most sales?
* How are sales changing over time?
* Which products or regions are growing or declining?
* Which areas may need attention?
* Where are the best opportunities for growth?

## Dashboard Design

The dashboard should have a **modern, clean, and professional look**.

The design should include:

* Clean KPI cards.
* Modern bar charts.
* Sparklines to show trends over time.
* Clear visual hierarchy.
* Consistent colors and formatting.
* Minimal unnecessary borders and visual clutter.
* Easy-to-read titles and labels.
* Consistent spacing and alignment.
* Interactive slicers with a simple design.

The dashboard should look suitable for a professional business or portfolio project.

## KPI Requirements

The main dashboard should highlight important metrics such as:

* Total Sales
* Total Profit
* Total Quantity
* Total Customers
* Total Orders
* Average Sales

Each KPI should be easy to understand at a glance.

Where appropriate, KPI cards should include **sparklines or small trend indicators** to show whether performance is increasing or decreasing over time.

## Sales Analysis

The report should provide a clear view of sales performance.

Users should be able to:

* Compare sales across different periods.
* Identify sales trends.
* Compare products and categories.
* Analyze sales by region.
* Identify top and bottom performers.

### Bar Charts

Modern bar charts should be used for comparisons such as:

* Sales by Product.
* Sales by Category.
* Sales by Region.
* Top 10 Products.
* Top-performing customers.

Bar charts should use clear sorting, readable labels, and consistent colors.

## Trend Analysis

The report should show how sales change over time.

Where appropriate, use:

* Line charts for major trends.
* Sparklines for compact trend views.
* KPI trend indicators.
* Monthly or yearly comparisons.

Sparklines should be used when they provide useful context without taking up significant dashboard space.

## Product Analysis

The report should help users understand product performance.

Users should be able to identify:

* Best-selling products.
* Products with declining sales.
* Product categories with strong performance.
* Product categories requiring attention.
* Sales trends for individual products.

## Regional Analysis

The report should provide an easy way to compare regional performance.

Users should be able to:

* Compare sales between regions.
* Identify high-performing regions.
* Identify low-performing regions.
* Analyze regional sales trends.

Modern bar charts and maps should be used where appropriate.

## Interactivity

The report should allow users to:

* Filter by date.
* Filter by product.
* Filter by category.
* Filter by region.
* Interact with charts.
* Cross-filter visuals.
* Navigate between report pages.

Filters should be easy to find and use without taking too much space on the dashboard.

## Visual Design

The overall design should follow a modern Power BI style.

### Colors

Use a consistent color palette throughout the report.

Primary colors should be used for important metrics, while secondary colors should be used for comparisons and supporting information.

Avoid using too many colors at the same time.

### Layout

The report should:

* Use a clean grid layout.
* Keep important KPIs at the top.
* Place major analysis visuals in the center.
* Keep supporting visuals toward the bottom.
* Maintain consistent spacing.
* Align visuals carefully.

## Expected Result

The final Contoso Sales Analytics report should look modern, professional, and easy to understand.

A user should be able to open the dashboard and quickly understand the current sales situation without having to study every visual.

The combination of **KPI cards, modern bar charts, trend visuals, and sparklines** should provide both a quick overview and enough detail for deeper analysis.

## Deliverables

The project should include:

* Power BI report.
* Modern Executive Dashboard.
* Sales Analysis.
* Product Analysis.
* Regional Analysis.
* Requirements documentation.
* README documentation.
* Screenshots of the completed report.
